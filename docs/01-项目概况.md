# 01 · 项目概况

> 技术栈 / 架构 / 目录结构 / 启动方式。改环境或接手项目时读本篇。

---

## 一句话定位

基于 **Vue3 + Express + SQLite** 的全栈单机超市管理系统，覆盖商品、库存、销售收银、会员、采购、退货、报表、批次保质期等核心业务。定位：毕业设计 / 中小超市可用。

---

## 技术栈

| 层 | 技术 |
|---|---|
| 前端框架 | Vue 3（`<script setup>` Composition API） |
| 路由 | Vue Router 4（含导航守卫） |
| 状态 | Pinia 3 |
| UI 库 | Element Plus 2 |
| 图表 | ECharts 5 |
| HTTP | Axios |
| 构建 | Vite 5 |
| 后端 | Node.js + Express 5 |
| 数据库 | better-sqlite3 12（**同步** API） |
| 认证 | JWT（jsonwebtoken）+ bcryptjs |
| 上传 | Multer 2 |
| 导入导出 | xlsx（Excel）、docx（Word）、file-saver |

## 规模

- 前端 ~10145 行：16 视图 + 9 复用组件
- 后端 ~4400 行：15 路由 + 中间件 + 工具
- 数据库：14 张表

---

## 架构

**前后端分离**，前端 SPA 通过 `/api/*` 与后端通信。

```
浏览器 (Vue SPA :5173)
   │  axios  Authorization: Bearer <JWT>
   ▼
Express (:3000)
   │  authMiddleware → roleMiddleware → 路由处理
   ▼
better-sqlite3 (supermarket.db, WAL 模式)
```

### 鉴权分层（已确认正确，见 index.js:22-36）

| 层级 | 挂载 | 路由 |
|---|---|---|
| 公开 | 无 | `/api/auth` |
| 登录级 | `authMiddleware` | `categories` `products` `members` `sales` `returns` `dashboard` |
| 管理员级 | `authMiddleware` + `roleMiddleware('admin')` | `member-levels` `users` `suppliers` `purchases` `batches` `reports` `logs` |

角色：`admin`（管理员）/ `cashier`（收银员）。

## 目录结构

```
超市管理系统/
├── server/                # 后端
│   ├── routes/            # 15 个 API 路由
│   ├── middleware/        # auth（鉴权）/ upload（上传）
│   ├── utils/             # calc（纯计算）/ logger（日志）
│   ├── db.js              # 连接 + 建表 + 触发器 + 种子数据
│   ├── config.js          # 环境配置（读 .env）
│   ├── index.js           # 入口 + 路由挂载
│   └── seed-demo.js       # 演示数据脚本
├── src/                   # 前端
│   ├── views/             # 16 个页面
│   ├── components/        # 9 个复用组件
│   ├── api/               # API 封装（request.js + 各模块）
│   ├── stores/            # Pinia（user.js）
│   ├── router/            # 路由 + 守卫
│   └── styles/            # tokens.css（设计令牌）+ global.css
├── public/products/       # 商品图片（部署开箱即用）
├── uploads/products/      # 用户上传图片
├── docs/                  # 本知识库
├── README.md / 使用说明文档.md / 答辩说明.md
└── package.json
```

## 启动与命令

| 命令 | 作用 |
|---|---|
| `npm install` | 装依赖 |
| `npm start` | **同时**启动前后端（concurrently） |
| `npm run server` | 仅后端 → http://localhost:3000 |
| `npm run dev` | 仅前端 → http://localhost:5173 |
| `npm run build` | 前端生产构建 |
| `npm test` | 跑单元测试（node --test） |
| `npm run smoke` | 冒烟测试 |
| `npm run seed:demo` | 灌入演示数据 |

**默认账号**：`admin` / `admin123`（首次启动自动创建）。数据库首次启动自动建表 + 填充示例数据。

---

## 关键环境说明

- 数据库文件：`server/supermarket.db`（WAL 模式，含 `-shm`/`-wal` 副本文件）
- 配置来自 `.env`（已存在），`config.js` 提供默认值兜底
- `JWT_SECRET` 生产环境务必经 `.env` 覆盖默认值
