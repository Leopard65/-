# 03 · 交付检查清单

> 用于最终交付、答辩演示和后续接手验收。

## 交付口径

- 本地源码可运行：`npm install`、`npm start`。
- 前端可构建：`npm run build`。
- 后端核心业务可测：`npm test`、`npm run smoke`。
- 演示包可生成：`npm run package:demo`。
- 演示包可独立启动：解压后执行 `START_DEMO.ps1`，访问 `http://localhost:3000`。

## 功能验收

- 管理员可完成商品、分类、采购、库存、批次、会员、供应商、报表、日志、用户管理。
- 收银员可完成商品搜索、扫码输入、购物车、会员折扣、挂单、结算、小票、退换货。
- 库存闭环覆盖智能补货、采购草稿、入库、低库存预警、盘点、调整、报损、批次清理。
- 经营分析覆盖销售趋势、利润、库存价值、异常雷达、会员 RFM、复购、经营周报导出。
- 审计闭环覆盖登录、用户变更、库存操作、销售、退货、批次清理和风险日志筛选。

## 质量门

- `npm test` 必须通过。
- `npm run build` 必须通过。
- `npm run smoke` 必须通过。
- 提交前 `git status --short` 只允许出现本轮计划内改动。
- 涉及数据库结构时必须保持首次启动自动建表、旧库轻量迁移可执行。

## 停机条件

- 所有 Loop 计划任务完成。
- 无已知阻塞错误。
- 测试、构建、冒烟、演示包生成全部通过。
- README、使用说明、未来规划与本清单同步。
