# 02 · 未来体验与 UI 规划

> 面向后续迭代的产品想象与执行路线。重点围绕管理员、收银员的使用体验，以及系统整体 UI 的专业感、效率感和可信度。

---

## 当前判断

项目核心业务已经覆盖商品、库存、销售、会员、采购、退货、报表、批次保质期、用户与日志等模块；代码中没有发现明确 `TODO/FIXME` 类未完成任务。后续更适合从“可用”进入“好用、好看、好交付”的阶段。

当前界面已经有统一的绿色经营主题、Element Plus 基础组件、仪表盘和收银台等关键页面。下一阶段建议把体验目标定为：

- 管理员：更快看懂经营状况，更早发现风险，更少在表格中来回跳转。
- 收银员：更快完成收银，更少出错，更像真实门店 POS。
- 系统 UI：从毕业设计可用界面升级为中小商超可长期使用的运营工作台。

---

## 设计方向

### 视觉关键词

- 经营感：数据清晰、状态明确、重点数字一眼可扫。
- 门店感：商品、价格、库存、收银动作有真实场景气质。
- 低干扰：后台系统避免过多装饰，把颜色让给状态、风险和操作。
- 轻活力：登录页和空状态可以保留一点生动角色，让系统不冰冷。

### UI 语言

- 保留主色 `#176b4d` 作为经营绿，继续用货架价签黄作为强调色。
- 表格、筛选、弹窗、按钮状态继续收敛到设计令牌，避免各页面手写尺寸。
- 首页和报表页可以更像“经营驾驶舱”，收银页更像“高密度操作台”。
- 卡片仅用于明确容器，不做卡片套卡片；业务页面以面板、工具栏、表格和状态标签为主。

## 管理员体验升级

### 1. 经营驾驶舱 2.0

把仪表盘从“数据展示”升级为“今日要做什么”：

- 顶部展示今日销售额、订单数、毛利估算、客单价、库存风险、待处理退货。
- 待办提醒支持优先级：缺货、过期、低库存、待审退货、异常高退货率。
- 图表支持切换今日 / 近 7 天 / 本月，不离开首页完成基础判断。
- 每个风险卡片直接跳转到带筛选条件的目标页面，例如“缺货商品”进入库存页并自动筛选。

### 2. 商品与库存工作台

管理员最常做的是维护商品、补货、处理预警：

- 商品列表增加图片缩略图、库存健康状态、毛利率、最近销售速度。
- 库存预警增加“建议补货量”，按近 7 天销量和安全库存估算。
- 批次页增加“先进先出提示”，帮助临期商品优先销售或促销。
- 采购页加入供应商维度统计：最近采购额、到货稳定度、常购商品。

### 3. 报表分析增强

报表页从单纯统计升级为“经营复盘”：

- 商品销售排行支持按销售额、销量、毛利、退货率切换。
- 增加时段热力图，识别高峰收银时段。
- 增加会员贡献分析：普通 / 银卡 / 金卡会员的销售占比与复购。
- 支持一键导出“经营周报”Word/PDF，适合作为毕业答辩和真实门店汇报亮点。

### 4. 管理安全感

- 用户管理增加最近登录时间、最后操作时间、账号风险状态。
- 操作日志增加模块筛选、关键字搜索、风险操作标记。
- 对删除、禁用、清库存等高风险操作使用二次确认，并展示影响范围。

## 收银员体验升级

### 1. 收银台更像 POS

收银员需要快，不需要复杂：

- 商品搜索支持条码 / 拼音首字母 / 商品名模糊搜索。
- 购物车固定在右侧，数量可用 `+` / `-` 快速调整。
- 常售商品区支持置顶，减少重复搜索。
- 支付区强化应收、优惠、实收、找零，数字使用等宽字体。

### 2. 键盘优先工作流

真实收银场景鼠标越少越好：

- `/` 聚焦商品搜索，`Enter` 加入购物车。
- `F2` 选择会员，`F4` 挂单，`F8` 结算，`Esc` 取消弹窗。
- 结算成功后自动清空并回到搜索框。
- 所有快捷键在界面中用轻量提示呈现，不做大段说明。

### 3. 会员识别与优惠透明

- 输入手机号后即时显示会员姓名、等级、折扣、积分余额。
- 结算区展示“原价 - 会员优惠 = 应付”，让收银员容易解释。
- 小票可显示本次积分、本次优惠和会员升级进度。

### 4. 错误防护

- 库存不足时直接在购物车行内提示，不等到提交才报错。
- 已下架商品不可加入，搜索结果中直接标灰。
- 退货时展示原订单明细，减少错退、重复退。

## 大胆一点的未来想法

### 智能补货助手

根据近 7 / 30 天销量、当前库存、保质期和供应商到货周期，生成补货建议。管理员可以一键把建议转成采购草稿。

### 门店异常雷达

自动标记异常情况：某商品退货率突然升高、某收银员取消订单过多、某类商品库存周转变慢。首页用“异常雷达”提醒，而不是让管理员自己翻报表。

### 角色化首页

管理员登录看到经营驾驶舱；收银员登录直接进入收银台，并在侧栏减少无关入口。不同角色不只是权限不同，而是首页任务不同。

### 可配置主题与密度

提供“标准 / 紧凑”密度切换。答辩和演示时用标准模式更美观，真实门店长期使用时用紧凑模式提高信息密度。

### 交互动效系统

保留登录页角色这种轻松感，但业务页动效只服务反馈：保存成功、库存预警、结算完成、图表切换。动效要短、稳、可关闭。

## 建议执行路线

### 第一阶段：桌面端体验打磨

1. 优化登录页比例、表单视觉重心和桌面宽屏表现。
2. 统一业务页面的面板、表格、筛选栏、按钮高度和间距。
3. 梳理收银台的主路径：搜索商品、加购、选会员、结算、打印小票。

### 第二阶段：角色体验分流

1. 管理员首页强化待办、风险和经营图表。
2. 收银员首页直接进入收银台，弱化非高频模块。
3. 侧边栏根据角色和任务重新分组，减少认知负担。

### 第三阶段：智能与自动化

1. 上线补货建议、异常提醒、会员升级提醒。
2. 报表支持经营周报导出。
3. 日志与风险操作形成安全审计闭环。
